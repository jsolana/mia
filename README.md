# Master in Artificial Intelligence (MIA)

This repository contains all the material, notes, experiments, and projects developed during my Master's Degree in Artificial Intelligence.

The goal is to build a structured knowledge base that combines theoretical concepts, practical implementations, scientific literature, and personal projects throughout the program.

---

## Repository Structure

```text
mia/
│
├── README.md
├── knowledge/
├── notebooks/
├── projects/
└── resources/
    ├── books/
    ├── papers/
    ├── slides/
    └── others/
```

### `knowledge/`

This directory contains my personal knowledge base.

It is managed with **Obsidian** and stores notes written in my own words. Each note focuses on a single concept, algorithm, technique, or topic.

Examples:

* Linear Regression
* Random Forest
* Q-Learning
* Transformer
* SHAP

The objective is not to copy books or papers, but to summarize, connect ideas, and document my own understanding.

---

### `notebooks/`

This directory contains **Jupyter Notebooks**.

Each notebook includes practical experiments, code implementations, visualizations, and conclusions related to the concepts studied.

Typical notebook contents:

* Data loading
* Data preprocessing
* Model implementation
* Training
* Evaluation
* Visualizations
* Conclusions

---

### `projects/`

This directory contains complete projects developed during the master's program.

Each project is self-contained and may include:

* Source code
* Datasets
* Notebooks
* Documentation
* Reports
* Presentation material

---

### `resources/`

This directory stores reference material used during the master's program.

#### `books/`

Reference books, manuals, and official documentation.

#### `papers/`

Scientific papers from sources such as arXiv, IEEE, ACM, Springer, Nature, and other academic publishers.

#### `slides/`

Lecture slides, presentations, and course material.

#### `others/`

Additional resources such as cheat sheets, tutorials, guides, diagrams, datasets descriptions, and any material that does not fit into the previous categories.

---

## Workflow

The learning workflow followed in this repository is:

```
Resources
      ↓
Study
      ↓
Knowledge (Obsidian)
      ↓
Experiment (Jupyter)
      ↓
Project
```

1. Read books, papers, or course material.
2. Summarize concepts in the knowledge base.
3. Validate ideas through experiments in Jupyter notebooks.
4. Apply the acquired knowledge to complete projects.

## Purpose

This repository is intended to become a long-term knowledge base rather than simply a collection of course materials.

Every concept should ideally be represented by:

* A knowledge note explaining the theory.
* One or more Jupyter notebooks demonstrating the implementation.
* References to the original books or scientific papers.
* Practical applications within projects whenever possible.
